Publish your changes

  1. Click Download index.html. Your browser saves the updated page.
  2. On GitHub, open the website’s repository and choose Add file → Upload files.
  3. Drop the downloaded index.html into the page (it replaces the old one) and click Commit changes.
  4. GitHub Pages republishes the site, usually within a minute or two.

Good to know

  • Your edits are kept as a draft in this browser until you discard them, so closing the tab doesn’t lose work.
  • To post news, click + Add news item. It appears at the top of the News feed on Home with this month’s date; type over the text and add a link if you like. Delete old news by hovering it and clicking Delete.
  • To add a publication, person or list entry, hover an existing one and click Duplicate, then edit the copy.
  • To change where a link points, click the link and edit the address in the toolbar.
  • Pasted text is inserted without outside formatting. Use Shift+Enter for a line break.
  • Opened from your computer instead of the website? Use Open file… and pick index.html.
